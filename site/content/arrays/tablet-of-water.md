## Characteristics

The Water array is associated with:
- **Defensive play** — pieces positioned for protection
- **Patience** — slower development favoring long-term strategy
- **Adaptability** — fluid response to opponent threats
- **Team coordination** — allies move consecutively for combined tactics

## Turn Order: Allies Together

Unlike the Tablet of Fire's clockwise order (Blue → Red → Black → Yellow), the Tablet of Water uses a **consecutive ally sequence**:

1. <span class="army-badge army-badge--blue">Blue</span> (Team Air)
2. <span class="army-badge army-badge--black">Black</span> (Team Air)
3. <span class="army-badge army-badge--yellow">Yellow</span> (Team Earth)
4. <span class="army-badge army-badge--red">Red</span> (Team Earth)

This creates a fundamentally different tactical rhythm — each team gets **two consecutive moves** before handing control to the opponents. This enables:

- **Coordinated attacks** — set up with one army, strike with the other
- **Combined defense** — block threats from multiple angles
- **Sacrifice combinations** — one army clears the way for the other

## Strategic Implications

The Water configuration rewards patient, methodical play:

- **Opening**: Focus on developing both allied armies before engaging
- **Midgame**: Use consecutive moves to create unstoppable two-army combinations
- **Endgame**: Coordinate throne attacks when opponent armies are frozen
